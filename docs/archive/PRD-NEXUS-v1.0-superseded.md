## 1. 产品目标与成功指标

### 1.1 三个正交产品目标

| 编号 | 目标 | 可衡量判据 | 关联 |
| --- | --- | --- | --- |
| **G-N1 · 稳定** | 8 产品叠加不破坏既有站群 | 既有 7 站产物哈希**零变化**；Frozen Core 11 文件哈希不变；147 项合规断言 0 失败 | INV-1/2/3/5 |

### 1.2 北极星指标（North Star Metric）

> **NSM = 周有效静默完成会话数（Weekly Completed Quiet Sessions, WCQS）**
> 定义：一个匿名会话内**完成至少一次产品主交互**，且全程未触发打扰元素、未出现未捕获异常、未在降级态报错的会话计数。

**为什么是它**：项目零消费引导、无任务体系、零 PII、纯前端，唯一同时满足「对齐用户价值（获得一次完整的平静 / 情绪表达）」与「在现有埋点能力下可测（匿名单向事件 + 分桶）」的指标。PV、停留时长、点击数都不等于「价值交付完成」。

| 项 | 内容 |
| --- | --- |
| 数据来源 | 现有 `analytics` 匿名事件通道（F7），需**新增**「主交互完成」「凭证导出」事件（NX-I-01） |
| 目标值 | 【假设】上线后 4 周建立基线，基线前**不设绝对目标**；首期目标为「8 产品全部可上报 WCQS 且口径一致」 |
| 校准方式 | 【假设·待校准】上线 4 周后用真实埋点回填基线，替换所有假设值；校准前任何百分比目标不得写进验收结论 |

### 1.3 支撑指标（AARRR 变体，剔除收入维度）

> **本项目零消费引导 → 无收入 / 无转化 / 无付费类指标**（对应 v1.0 G3 与 INV-5）。下表「可测性」列严格受 F7 约束。

| 维度 | 指标 | 口径 | 可测性 | 目标 |
| --- | --- | --- | --- | --- |
| **获客 Acquisition** | 独立入口进入数 | 8 个新页各自的匿名「页面进入」事件去重计数 | ✅ 现有埋点可测 | 【假设】4 周建立基线 |
| | `?from=` 来源入口数 | 回赠链接带来的进入事件 | ✅ F8 已验证可解析 | 【假设】4 周建立基线 |
| **激活 Activation** | 主交互完成率 | 完成主交互会话 / 进入会话 | ✅ 需新增完成事件 | 【假设】4 周建立基线 |
| | 首交互时长分桶 | 进入 → 首次交互的分桶时长（沿用 `bucketDuration`） | ✅ 现有能力 | 【假设】仅观测，不设阈值 |
| **留存 Retention** | **严格意义次日留存不可测** | 零 PII + 无服务端 + 无跨会话 ID（F7） | ❌ **不可测，不得承诺** | — |
| | 替代：会话内跨产品衔接率 | 单会话连续完成 ≥2 个产品的会话占比（产品 ③ 天然串四站） | ✅ 可测（会话内） | 【假设】作为留存代理，需 Q-N5 确认 |

> **诚实声明**：因 F7（无服务端 API、零 PII），**无法做用户级留存、渠道归因、漏斗去重到自然人**。上表所有「留存」均为会话内代理指标；任何「留存率 X%」「DAU」类表述在具备后端与合规授权前不得出现。这是产品约束，不是遗漏。

| E3 | **配置驱动、不改 glue** | 换文案 / 换配色 / 换场景是运营动作，不应每次都发版改代码 | 仅改配置重建后产物变化、glue 源码零改动（INV-8）；沿用既有 L2 五常量注入口径 |
| E4 | **既有产物零变化** | 「稳定」的唯一硬证据：老用户访问老站点不该因为上线新品而看到任何变化 | 8 产品全部上线后，7 站产物哈希与 QA §1 基线逐字节一致（INV-3） |
| E5 | **后续叠加只追加配置** | 「扩展」= 边际成本递减；第 9、第 20 个产品的成本应低于第 1 个 | 按 SOP §7 追加一条配置即可产出新站，且既有产物零变化 |
| E6 | **组合生命周期互不干扰** | 叠加越多越容易出现「A 零件把 B 零件的音景 / 后处理踩掉」，直接毁掉体验 | 多零件同层（产品 ①）与各产品组合冒烟无冲突、无泄漏（INV-7） |

> **边界**：Frozen Core（L0）一行不改属 INV-1；「深度调整」作用于 L1/L2/L3 层，本 PRD 不为 L0 开任何口子。所涉 R1/R3 由架构师 G2 裁决（§10.1）。
