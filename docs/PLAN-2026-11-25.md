## 0. 一句话结论

## 2. 四视角问题诊断

### 2.1 用户使用 / 体验视角

**硬事实：四站没有一站按 `PRODUCT-FORM` 的三条判据全绿；6 个体验阻断（四站 4 个 + A2 2 个）。**

| 站 | 用户看到什么 | 关键问题 |
|---|---|---|
| `/license` | 桌面 0.7 s 可见、57 fps；盖章 6.4 s；`Save it` 能导出 PNG | 手机 390 宽 approved 后文字互相重叠；`Save it` 无完成反馈；折角只有键盘 `F`；二级文字对比度 2.5–2.9:1；导出光照与屏幕不一致 |
| `/hug` | 桌面 0.55 s、57 fps；点草地会放飞蒲公英 | **点草地放飞不给链接**，只有按钮/键盘路径写剪贴板；开 Wind 后环境噪音会把蒲公英不可逆全部放飞（`audio.level > 0.12`，RMS 还被乘了 3）；没有 ≥40 s 单向慢变量 |
| `/still` | 体素海底，画面本身有辨识度 | 遮罩 16–45 s 纯黑无文字；手机只画左上角约 390×260；无 WebGPU 时静止渐变、`Sit` 无反应、无提示；124 s 仍无带走物；桌面 32 fps / `renderScale 0.55` / degraded |
| `/koi` | 水墨锦鲤，视觉成立 | 首屏 5–7 s 黑屏（桌面 6 s 前读不到画布）；菜单 12 项、无聚焦元素；无带走物/导出；`?style=real&cam=angle&rain=rain` 只有 4.1 fps |
| 入口页 | `dist/index.html` | 裸 `<ul>` 列表，没有 H1/说明/首帧；没有 favicon；四站全部列出，包括没走通全链路的站 |
| A2 Studio | 5 个模板 + 25 个控件 | 没有导出；5 个模板同时常驻，首开 11.1 MB；temple/gate 预览 16–31 s；调参整页重载 iframe（拖 1.2 s 触发 18 次重载）；手机控件 13×13 复选框、10 px 标签；调试条盖住预览约 6 成 |

**用户体验层面的根因不是“画面不够多”，是“打开后不知道能做什么、做完带不走、手机不能用”。** `/license` 是唯一走通“打开→看懂→停留→带走”的站；其余三站都缺至少一段。

### 2.2 产品视角

1. **四站产品实际上是“1 个能交付 + 3 个 demo”**：`/license` 全链路成立，但 G1/G7 仍不过；`/hug` 缺带走链接；`/still` 画面坏在手机和降级环境；`/koi` 没有带走物且启动黑屏。
2. **A2 是“模板集合”，还不是“模板产品”**：5 套都能开、`file://` 直开、零外部请求；但 Studio 没有导出，体积 >1 MB 无预警，调参靠整页重载，没有画质档位，调试条直接给用户看。A2 六项 Must 为 **1 达成 / 3 部分 / 2 未达成**。
3. **场景供给过剩、产品消费不足**：17 件 Stage 零件里 4 件孤儿；28 个内部模块里 9 个 room 模块没用；19 个 rain/crimson 视觉件只有边界。继续拆不会让产品更好。
4. **两条产品线混在一个入口**：四站是“情绪站”，A2 是“可导出模板”；现在同一仓库、同一套零件，但入口、验收、体积约束不同。需要分线、分入口，不建议分仓。
5. **体积约束没有变成产品约束**：temple / gate gzip 3.47 MB，是 1 MB 线的 3.4 倍，却仍显示绿色 `READY`；`deepsea` 是 Canvas2D，不是粒子实现；A2 的“平台门槛”没有落到构建/Studio。

4. **先收口，后扩张**：不再拆第三方、不再加 A2 模板；先把导出/体积/调参补齐。
5. **每个 P0 有可截图或可复跑命令的完成判定**，不靠“看起来好了”。
